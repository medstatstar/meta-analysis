## 4. 关键教训 / 一致性约定（防回归）

1. **静默失效高发区清单**（本日三次踩中，移交时重点盯）：
   - 跨技能透传字段（如 `params.sources`）：上游 `arg_map` 没映射 + 下游 CLI 没参数 → 静默丢。改一处必查上下游两处。
   - 配 key 机器的本地优先路由会**跳过 Coze**，导致依赖 Coze 的副作用（飞书留痕）静默失效 → 用 `force_coze` 逃生开关显式绕过。
   - 镜像端 pydantic 未声明字段 → 被静默丢弃（skill_version 根因）→ 改契约字段必查两端（客户端 + 镜像 state.py）。

2. **菜单选项派生铁律**：一切选项来自状态机（`_REDLINE_GATES`/`EDITABLE_KEYS`），渲染层只读状态、不做第二遍硬编码。新增/改选项先改 `EDITABLE_KEYS` 与 `_aN_options`，再补 `build_decision` 与测试。

3. **修订（revised）语义**：A1 阶段的修订是「检索前最后可改点」，**只补丁信封、停回本节点等批准**，绝不可走通用 `_advance` 重跑整块（会跳过 A1 批准闸 + 触发无谓全库检索）。仅跨块回退（如 A2 改已离开的块）才走 rewind 真重跑。

4. **源集合真源唯一**：`AVAILABLE_SOURCES` 必须等于 ct-literature `fetch_coze_unified._SOURCE_DISPLAY`（6 真源），不准凭记忆写 PubMed/Cochrane/WoWS/Scopus 这类别名/子模式/无授权源。

5. **本地验证环境**：UNC 慢盘下全仓 `grep`/`find` 极慢易超时，改「定向 Read + 单文件 Grep」；镜像 `.venv` 失效，验证用 `uv run --no-project --with pydantic`；临时验证脚本用完即删（本日 `_verify_*.py` 已清）。
