## 1. 现状与缺口

| 能力 | 工作台（已有） | 对话侧（现状） | 缺口 |
|---|---|---|---|
| 阶段地图 | 左栏 12 节点时间轴 | Stage 0 口头列一次 5 段 | **每轮无位置感** |
| 节点面板 | `schema_for()` 逐节点渲染（7 种 panel kind） | 无 | **展示什么、怎么展示靠即兴** |
| 闸位选项 | 按钮：批准/修订/打回/跳过 | 无 | 红线"不可跳过"等约束**会漂** |
| 回退 / 审计 | `/api/rewind`、右栏日志 | 无 | 改上游只能重开；答不出"我批过什么" |
| 重交互能力 | 上传/拖拽指派/PDF 页码预览/大表逐条编辑 | 无（且**不该硬做**） | v0.2 起明确：**部分能力不进对话** |

**根因**：全流程只有 HTML 表单那套是结构化的；对话侧缺的是**菜单契约**，不是又一份说明文档。

## 2. 目标 / 非目标

**目标**：G1 状态可见 · G2 闸位可操作（该节点专属选项）· G3 可回退 · G4 零漂移（同源 `form_schema`）· G5 零额外成本（无浏览器/端口）。

**非目标**

- N1 不做"把工作台搬进终端"：**A3 逐条裁决、A4 逐篇核验等重度交互以工作台为主**；对话侧只做 Top-N + 文件交接，**不做残废版**。
- N2 不改计算轨道（Type-Compute）：纯算数请求继续"描述即执行"，不弹任何流程菜单。
- N3 不改 `form_schema` 既有语义（工作台面板结构不动，只**加一层投影**）。
- **N4（v0.2 新增）对话侧不实现需要视觉/空间信息的操作**：PDF 页码预览、图片、并排对比、拖拽指派——一律 ④ 转出。

## 3. 三层菜单结构

### L0 · 上下文导航条（每轮一行）
```
流程 [✔]①选题 [✔]②检索 [▶]③初筛 [ ]④提取 │ [ ]⑤合并 [ ]⑥GRADE [ ]⑦声明 [ ]⑧质量门 │ [ ]⑨初稿 [ ]⑩评审 [ ]⑪参考 [ ]⑫QA
```
`✔` 已过闸 · `▶` 当前停靠 · `[🔴]` 红线未过 · `[!]` 有待办未清 · `[ ]` 未达。

### L1 · 节点菜单（停在闸位时）
三件套：**节点头（闸类 + 待办标记）+ 数据摘要（对话投影）+ 穷举编号选项**。实例（A3）：

```
③ 初筛 · 逐条裁决            〔软停 · 需你拍板〕
   去重 42 → 纳入 12 / 剔除 28 / 低置信 2 ｜ 疑似综述默认剔除 3
   ── 逐条（Top 5 / 共 42；逐条修改走文件交接）
   1. Zhang 2023 · J Clin Oncol · RCT        [纳入]
   2. Lee 2021  · BMJ          · 综述·疑似   [剔除]
   ── 你的选择
   [1] 批准放行 → 进 ④ 数据提取（🔴 红线，不可跳过）
   [2] 修订（⬇ 导出裁决表 → 改完 ⬆ 传回）
   [3] 跳过本阶段（软停专属）
   [4] 打回 / 回退到更早阶段
   [5] 解释本节点在做什么
   [6] 看原始数据（只读 JSON）
```

### L2 · 字段菜单（选"修订"后）
只列该节点的 `EDITABLE_KEYS`，且**只给对话可行的改法**（详见 §8.5）：定位式修改优先，整篇重输仅限短文本。

### 全局指令
`/flow` 重画菜单 · `/node <id>` 回看 · `/rewind <id>` 回退重算 · `/explain <id>` 讲清节点 · `/raw` 原始 JSON · `/workbench` 切工作台（同一 session）· `/export` 导出审计 · **`/todo` 列出待办（v0.2 新增）**

## 4. 渲染映射（`form_schema` kind → 对话形态 + 处置策略）

| kind | 工作台 | 对话 CCM | 策略 |
|---|---|---|---|
| `object` | 键值区 | Markdown 两列表 | ① 原生 |
| `dicttable` | 表格 | Markdown 表（≤6 列） | ① / ② |
| `rowlist` | 可编辑表 + 筛选 + ⬇⬆ | Top-N + "还有 N 条" + 文件交接 | ③ 文件交接 |
| `textarea`（短） | 文本框 | 引用块 + `改 <字段> <新内容>` | ② 降级 |
| `textarea`（长，>1 屏） | 文本框 | 摘要 + 指哪改哪；整篇重写转出 | ② / ④ |
| `bool` | 勾选框 | 选项 `是 / 否` | ② 降级 |

| `a4documents` | 逐篇卡片 + 拖拽指派 + PDF 预览 | 逐篇文本行 + 字段级修订；指派/预览转出 | ② / ④ |

## 5. 闸位与动作矩阵（对齐 `_validate_decision`）

| `await_kind` | 节点 | 可选动作 | 对话侧硬约束 |
|---|---|---|---|
| `pause`（软停） | A1 A2 A3 C1 | 批准 / 修订 / **跳过** / 打回 | 跳过 = 本会话不再停靠该节点，须显式说明 |
| `gate`（🔴） | A4 B4 C3 C4 | 批准 / 修订 / 打回 | **不得出现"跳过"**；选项由代码产出 |
| `handoff_confirm` | A→B、B→C | 批准 / 打回 | 仅两选项 |
| `guard_blocked` | B 块入口 | 批准（放行凭据） | 抽取 CSV 未 `stamp --confirm`；给解锁指引 |
| **`pending`（v0.2 新增）** | 任意（含 🔴） | 看待办 / 去工作台完成 / **defer** | `pending_actions` 非空 → **拒 `approve`** |
| `done` / `error` | 终态 | — | `error` 给"看错误 / 重试 / 导出诊断"，**不自动重试** |

### 5.1 `defer` ≠ `skip`（v0.2 关键区分）

| | `skip`（既有语义） | `defer`（本设计新增） |
|---|---|---|
| 含义 | 本会话**不再停靠**该节点，按默认值放行 | 该节点的**人工动作未完成**，流程**不得前进** |
| 适用 | 仅软停（A1/A2/A3/C1） | 任意节点，尤其 🔴 红线 |
| 后果 | 下游按默认值继续跑 | 闸位保持 `await`，输出「工作台待办清单」 |
| 审计 | 写 `human_decision(action=skipped)` | **不写** human_decision；写 `pending_actions`（带 `reason` / `hint` / `deeplink`） |
| 谁清除 | 无需清除 | 工作台完成对应操作后自动清空（或 `/todo` 复核后清除） |

> ⚠️ **二者绝不可混用**：把 `defer` 当 `skip` 处理 = 让红线的人工核验被静默绕过。
> `pending_actions` 是**双端共享**的待办清单：对话侧标的待办，工作台可见；工作台完成的，对话侧 `[!]` 消失。

## 6. 状态与跨轮连续性

### 6.1 回显块
```
## 当前流程设定 / Current pipeline settings: session=<path> | block=A | node=A3.screening | await=pause | gate=— | todo=0 | schema=v0.2 | next=A4.data_extraction
```
- 与计算轨道 `## 当前分析设定 /` 前缀不同、互不覆盖；同轮同现时分析块在后。
- `session` 是**指针**（路径），不搬数据本体（同 `continuity.md` §6.3）。
- `todo` 字段（v0.2 新增）= `pending_actions` 条数，非 0 时 L0 打 `[!]`。

### 6.2 追问规则
1. 每次渲染后回显该块；2. 追问先读**最近一个流程块**，只覆盖变化字段；3. 拿不准时 `flow_menu.py --status` 兜底——**状态真源在文件，不在 LLM 记忆**。

## 7. 触发与「不干扰」策略

| 场景 | CCM 行为 |
|---|---|
| 全流程触发 | **开启**：Stage 0 贴 L0 全图；此后每轮贴 L0，闸位自动贴 L1 |
| 计算轨道（合并 OR / NMA / 敏感性…） | **完全不开**（保持"描述即执行"）；仅 Complex 选型保留既有路由菜单 |
| 选题轨道 | **不开 L1**；报告末尾给 `[进入全流程？]` |
| 用户输入 `/flow`、`菜单`、`流程菜单` | 强制打印 L0 + 当前 L1 |
| 非闸位轮次 | 只贴 L0 一行（含 `todo` 计数） |
| `pending_actions` 非空 | L1 顶部插「待办清单」块 + `/workbench` 入口，**不放行选项置灰并在文案中说明原因** |

**调用预算**：闸位菜单渲染 = 1 次 `flow_menu.py`；不计入计算轨道"开火前 ≤1 调用"红线；禁止同闸位重复渲染。

## 8. 对话侧操作可行性分级（v0.2 新增）

### 8.1 核心原则：不做能力等价，做扬长避短

| 维度 | 工作台（GUI）强 | 对话（CCM）强 |
|---|---|---|
| 空间 / 视觉 | PDF 页码预览、图片、并排对比 | — |
| 批量结构化编辑 | N 条逐条改、多选、三态筛选、拖拽指派 | — |
| 读 + 单决策 | 点按钮 | 自然语言、可追问、可解释 |
| 歧义处理 | 需预设好全部按钮 | 「我拿不准」→ 现场讲清再选 |
| 回退 / 重跑 | 两下点击 + 确认弹窗 | 一句话 `/rewind A3` |
| 长文改写 | 框内编辑 | 指哪改哪 + 追问 |

**结论**：GUI 独有的操作，CCM 明确"请在界面做"，并给出待办与入口；**不做一个残缺版本**让用户来回折腾。

### 8.2 四问判定（一个操作该不该进 CCM）

1. 是否需要**视觉/空间信息**（PDF 页面、图片、并排）？→ **不进**
2. 是否涉及 **>10 条记录的逐条编辑**？→ **不进**（转文件交接）
3. 是否需要**多选 / 拖拽 / 指派**（文件 ↔ 条目映射）？→ **简化**（自动匹配 + 只问未匹配），失败转出
4. 是否只是**读 + 单一决策**？→ **优先进**

### 8.3 四种处置策略

| 策略 | 含义 | 典型 |
|---|---|---|
| **① 原生迁移** | 对话里原样做，甚至更好 | 只读清单、统计、确认、自动节点摘要 |
| **② 降级简化** | 换对话友好的形态做 | 大表→Top-N、长文本→指哪改哪、勾选→选项、单元格→字段级指令 |
| **③ 文件交接** | 对话只管"导出 → 改 → 传回" | A3 裁决表、A4 抽取表 |
| **④ 跳过 · 转出（defer）** | 对话不做，标记待办 → 工作台完成 | 视觉核验、拖拽指派、PDF 预览、长文重写 |

### 8.4 节点 × 操作分级表（12 节点 + 交接闸）

| 节点 | 工作台操作 | 对话策略 | 说明 |
|---|---|---|---|
| **A1** | PICOS 只读表 / 缺失维度 / 注册库探针 | ① | Markdown 两列表 + 一行告警 |
| | `include_reviews` 勾选 | ② | 选项问"是否纳入综述类文献？是/否（默认否）" |
| | PICOS 报告长文本 | ② | 摘要 + 指哪改哪（`改 P：…`），不整篇重输 |
| **A2** | 覆盖总览 6 字段 / 各库条数 | ① | 两列表 + Markdown 表 |
| | 检索式 textarea（长布尔式） | ② | 默认"接受"；要改则**粘贴新式**，不逐词编辑 |
| | 未翻译残留 / 沉默漏检告警 | ① | 对话最能讲清的地方 |
| **A3** | 统计 4 数 / 疑似综述徽标 | ① | 文本标记 |
| | **逐条裁决 rowlist（N 条）** | ③ | Top-N 预览 + ⬇⬆；**N>10 不做对话内逐条** |
| | 三态筛选栏（Tab 过滤） | ④ | 筛选器属 GUI 交互，对话不需要 |
| | 点行展开 18 字段详情 | ② | 仅对 Top-N 中被质疑条目按需展开 |
| **A4** 🔴 | 提取概览 3 数 | ① | — |
| | **逐篇 2×2 抽取行** | ② | 逐篇文本 + 来源引用（页/表 anchor）+ 字段级修订 + 剔除/恢复 |
| | ⬇ 下载全文并抽取（进度界面） | ④ | 对话不做进度界面；只给状态行 |
| | **待补传 PDF 上传** | ② | 用户在对话附文件或给路径 → 文件名/DOI 自动匹配；**只问未匹配项** |
| | 多文件批量匹配面板 / 拖拽指派 | ④ | 转工作台 |
| | **PDF 页码预览** | ④ | 视觉核验不可文本化 |
| | 逐篇剔除 / 恢复 | ② | 一行指令（`剔除 S7`） |
| **B1/B2/B3** | 合并摘要 / GRADE / 过度声明 | ① | 一行摘要（k · 效应量 · I²；分级 + 降级；命中清单） |
| **B4** 🔴 | 质量报告长文本 | ② | 摘要 + 指哪改哪 |
| **C1** | 章节清单 | ① | — |
| | 长文改稿 / 整篇重写 | ② / ④ | 指哪改哪可做；**整篇重写（>1 屏）转出** |
| **C2** | 评审意见 | ① | — |
| **C3** 🔴 | 撤稿 / 虚构 / 错配问题清单 | ① | 清单本身即裁决依据 |
| | 改参考文献（逐条 / 批量） | ② / ④ | 逐条可；批量转出 |
| **C4** 🔴 | 投稿前 QA 清单 | ① | — |
| **交接闸** | `n_studies` + 字段清单 | ① | 选项仅 批准 / 打回 |

**分布**：① 原生 ≈ 9 个节点主体面板；② 降级 ≈ 8 处；③ 文件交接 1 处（A3，A4 可复用）；④ 转出 ≈ 7 项（**集中在 A4 与长文场景**）。

### 8.5 三类差异专章

**（1）上传（Upload）**

| 工作台 | CCM |
|---|---|
| 拖拽 / 多选 / 就地指派到某篇 / PDF 页码预览 | 对话附文件或给本地路径 |
| 规则 | 单文件 + 上下文明确 → 直接接收；多文件 → 自动匹配（DOI / 标题 / 文件名）→ **只问未匹配**；匹配率低于阈值 → `defer` 转工作台 |
| 替代方案 | 用**文本来源引用**（"来源：p3 Table 2"）替代页面预览 |
| 硬约束 | `needs_user_upload > 0` 或存在未完成指派 → **不得 `approve`**，输出待办清单 |

**（2）选单确认（Selection / Confirmation）**

- 问题本质：GUI 里选项是**可见的**；对话里用户不知道有哪些选项。
- **规则 1**：选项必须由我方**穷举并编号**，禁止隐式"随便说都行"或开放式"你要继续吗？"。
- **规则 2**：选项 ≤3 → 可用卡片（`AskUserQuestion`，最接近 GUI 体验）；≥4 → 编号文本菜单 + 解析自然语言（"批准" / "1" / "a" / "就这样"）。
- **规则 3**：🔴 节点选项集中**禁止出现"跳过"**；且绝不把闸位做成自由文本问答。
- **规则 4**：保留 GUI 的二次确认语义——打回 / 回退 / 跳过前，先回显后果（"将清空 A3 及下游并重跑，耗时较长"），需再次确认。

**（3）编辑（Edit）**

- 大表格 → ⓐ Top-N 预览 + ⓑ 文件交接（③）
- 长文本 → 指哪改哪（定位 + 替换）；**超 1 屏 → `defer`**
- 开关 / 布尔 → 选项问（②）
- 结构化单元格（2×2、三态下拉）→ 只支持**字段级指令**（`改 S3 的 event_exp 为 12`），不支持自由光标编辑

### 8.6 反直觉：对话反而更强的地方（CCM 该主打）

- `/explain` 讲清"这个节点为什么需要我拍板"（GUI 无入口）
- "我拿不准，帮我对比两个选项" → 先讲临床/统计含义再选（对齐家族「解释差异」入口）
- 回退重跑一句话完成（GUI 需点两下 + 确认弹窗）
- A2 沉默漏检 / 覆盖缺口的自然语言解释
- 跨阶段追问（"刚才 A3 剔了哪几篇综述？"）→ 读 session JSON 直答

### 8.7 对验收标准的追加

| AC | 内容 |
|---|---|
| AC6 | 任一节点菜单中，④ 类操作**不出现**，且给出 `defer` 指引与 `/workbench` 入口 |
| AC7 | A4 在 `needs_user_upload > 0` 或存在未匹配指派时，`approve` 被拒（`pending_actions` 非空） |
| AC8 | 所有闸位菜单的选项为**穷举编号**，无自由文本式询问 |
| AC9 | `defer` **不写入** `human_decisions`，且不触发任何下游计算 |

## 12. 主要风险
