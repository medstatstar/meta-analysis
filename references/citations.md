# Meta-Analysis 技能引用规范

## 核心 R 包引用（完整版）

### 英文期刊引用格式

1. **R**: R Core Team (2024). R: A language and environment for statistical computing. R Foundation for Statistical Computing, Vienna, Austria. https://www.R-project.org/

2. **metafor**: Viechtbauer, W. (2010). Conducting meta-analyses in R with the metafor package. *Journal of Statistical Software*, 36(3), 1-48. https://doi.org/10.18637/jss.v036.i03

3. **meta**: Balduzzi, S., Rücker, G., & Schwarzer, G. (2019). How to perform a meta-analysis with R: a practical tutorial. *Evidence-Based Mental Health*, 22(4), 153-160. https://doi.org/10.1136/ebmental-2019-300117

4. **dmetar**: Harrer, M., Cuijpers, P., Furukawa, T. A., & Ebert, D. D. (2019). *Doing Meta-Analysis with R: A Hands-On Guide*. Chapman and Hall/CRC. https://bookdown.org/MathiasHarrer/Doing_Meta_Analysis_in_R/

5. **netmeta**: Rücker, G., Krahn, U., König, J., Efthimiou, O., & Schwarzer, G. (2016). netmeta: Network Meta-Analysis using Frequentist Methods. R package version 3.0-5. https://CRAN.R-project.org/package=netmeta

6. **bayesmeta**: Röver, C. (2020). Bayesian random-effects meta-analysis using the bayesmeta package. *Journal of Statistical Software*, 93(6), 1-48. https://doi.org/10.18637/jss.v093.i06

7. **bayesmeta (manual)**: Gül, A., & Akin, H. (2024). bayesmeta: Bayesian Meta-Analysis. R package version 3.7. https://CRAN.R-project.org/package=bayesmeta

8. **gemtc**: van Valkenhoef, G., Kuiper, J. (2021). gemtc: Network Meta-Analysis Using Bayesian Methods. R package version 1.3-0.

9. **dosresmeta**: Crippa, A., Discacciati, A., Bottai, M., Spiegelman, D., & Orsini, N. (2019). dosresmeta: Performing Multivariate Dose-Response Meta-Analysis. R package version 2.0.1.

10. **robvis**: McGuinness, L. A., & Higgins, J. P. T. (2021). Risk-of-bias VISualization (robvis): An R package and Shiny web app for visualizing risk-of-bias assessments. *Research Synthesis Methods*, 12(1), 55-61.

11. **metasens**: Schwarzer, G., Carpenter, J. R., & Rücker, G. (2023). *Meta-Analysis with R*. Springer. https://link.springer.com/book/10.1007/978-3-319-21416-0
